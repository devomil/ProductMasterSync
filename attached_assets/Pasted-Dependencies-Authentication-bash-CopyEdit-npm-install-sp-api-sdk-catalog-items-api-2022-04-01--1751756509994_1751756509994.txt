4. Parsing Response
API returns complex nested objects:
•	item.identifiers (UPC, EAN, etc.)
•	item.images with variant and link
•	item.salesRanks grouped by marketplace, classification, display group
•	item.relationships (e.g. variation parents/children)
•	item.attributes, item.dimensions, and item.classifications
Map these into your relational schema:
•	identifiers → product_identifiers
•	images → product_images
•	classifications → browse_nodes + mapping table
•	relationships → variation links
•	salesRanks → sales_rankings
•	attributes/dimensions → product_attributes

6. Integration Workflow
•  Call searchCatalogItems
•  Extract asin, matchConfidence, identifiers, images, etc.
•  For each promising asin, optionally call getCatalogItem for deeper data
•  Store results into your DB tables
•  Use confidence scoring + profitability + restriction logic to flag autotrade items

Step	Action	Notes
1	Setup SDK & Auth	Use @sp-api-sdk types
2	searchCatalogItems	Up to 20 identifiers, include rich datasets
3	getCatalogItem	Fetch additional details optionally
4	Parse & Normalize	Populate relational tables
5	Retry Logic	Auto retry on 429
6	DB Insert & Compute	Match, score, flag for purchase
